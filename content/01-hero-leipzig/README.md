# Фотографии Лейпцига для героя

**Сколько:** 8–12  
**Формат:** JPG, **вертикальные 4:5**, минимум **2400×3000**

Кадры города для крупных блоков на главной. Вертикальные —
потому что герой на телефоне вытянут вверх, а из горизонтального
снимка там останется полоска.

Снимайте около 15:00 в августе: квест идёт в это время, и вечерние
кадры с жёлтыми фонарями рядом с дневными выглядят чужими.

Имена: `hero-markt-01.jpg`, `hero-ratusha-02.jpg` — по месту.
