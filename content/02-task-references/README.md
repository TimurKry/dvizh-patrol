# Референсы для фото-заданий

**Сколько:** 6–9  
**Формат:** JPG/PNG, **горизонтальные 4:3**, минимум **2400×1800**

Образец на карточке задания: поза, которую надо повторить, или
объект, который надо найти.

Снимайте **объект, а не готовую сцену**: эталон — подсказка, а не
ответ. Иначе команды просто скопируют кадр.

Имена по номеру задания: `task-07-taksa.jpg`.

> Сейчас здесь лежат восемь снимков из первой загрузки — от 392 до
> 736 пикселей по ширине. Это в три раза меньше нужного, на
> телефоне будет мыло. Если есть оригиналы крупнее, замените.
