# Примерные команды

**Сколько:** 4–6  
**Формат:** Название, цвет, состав — можно вымышленные

Нужны, чтобы наполнить рейтинг и экраны команд на скриншотах и
при проверке — пустая таблица ничего не показывает.

Вымышленные подойдут: настоящие команды зарегистрируются сами.

Достаточно строки на команду: `Трамвай / кирпичный / Тимур, Аня,
Марк`.
