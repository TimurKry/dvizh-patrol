# Дизайн-система · V3 Mono Signal

Живая витрина: **`/design-system`** — единственная страница,
которая рендерится без базы. На ней видно всю палитру, шкалу и
компоненты; после правки токенов достаточно открыть её, чтобы
убедиться, что ничего не разъехалось.

Токены живут в `app/globals.css` в блоке `@theme`. Правки
вносятся там, а не в компонентах.

## Золото — единственное исключение из «сигнал ровно один»

`#c9a227` живёт только на золотой карточке: рубашка, рамка,
плашка баллов. Больше нигде.

Правило «сигнал ровно один» написано против интерфейса, где
каждый второй элемент кричит. Здесь наоборот: карточка одна на
всё мероприятие, и назвать её золотой, покрасив в тот же цвет,
что и остальные, — значит сказать одно, а показать другое.
Исключение оправдано тем, что оно не масштабируется: как только
золотых карточек станет две, оно перестанет работать и его надо
будет пересматривать.

Тёмный вариант `#8a6f14` — для текста и рамок на светлом:
`#c9a227` на `#f7f2e2` даёт 2.1:1 и в подписи не годится.

## Главная идея

Интерфейс чёрно-белый. Пурпурный `#FF00B3` — **один сигнал** на
всю систему: он означает «сюда» и больше ничего. Как только
пурпурного становится больше одного-двух элементов на экран,
сигнал перестаёт читаться и превращается в декор.

Цвета команд — отдельная история. Они существуют, их шесть, но в
интерфейс они не попадают: только рубашка карточки, орнамент,
маркер команды и связанные с командой детали.

### Что удалено окончательно

Кремово-кирпичная палитра, постерный layout, Oswald, Literata,
пятипунктная нижняя навигация, `dvizh-patrol-poster.jpg` и
`og-image.jpg`. Восстанавливать нельзя.

Фон не `#000000` намеренно: на OLED чистый чёрный даёт ореол
вокруг светлого текста, а границы панелей исчезают совсем.

Текст не `#FFFFFF` по той же причине с другой стороны — белый на

`--color-faint` подобран по худшему случаю — по панели `#121216`,
а не по холсту: этим цветом набраны подписи и внутри панелей.
На панели он даёт 4.85:1, на холсте 5.37:1 — оба проходят AA.

### Где сигнал уместен

Основная кнопка · countdown · активный пункт навигации · метка
«захвачено» · тонкие линейки · одна точка в знаке.

### Где сигнал запрещён

Границы карточек · поля ввода · таблицы админки · обычный текст ·
подсказки · вторичные кнопки · фон крупных областей.

### Цвета команд

Живут в `lib/team-colors.ts`, в базе хранится только ключ
(`teams.color`, enum `team_color`).

| Ключ     | Hex       | Текст поверх |
| -------- | --------- | ------------ |
| `red`    | `#FF3B30` | `#060609`    |
| `green`  | `#21C55D` | `#060609`    |
| `blue`   | `#2F80FF` | `#F5F5F1`    |
| `yellow` | `#FFD400` | `#060609`    |
| `orange` | `#FF7A00` | `#060609`    |
| `pink`   | `#FF00B3` | `#060609`    |

Пара «цвет / текст поверх» посчитана один раз здесь, а не
подбирается в каждом компоненте: на жёлтом и оранжевом белый
текст не проходит даже 3:1.

Компоненты читают цвет через CSS-переменные `--team-color` и
`--team-on-color`, которые ставит `teamColorVars()` на корне
командного экрана. Пропсами цвет не протаскивается: иначе его
пришлось бы передавать через каждый промежуточный компонент.

## Шрифт

| Токен            | Шрифт         | Вес     | Где                            |
| ---------------- | ------------- | ------- | ------------------------------ |
| `--font-display` | **Unbounded** | 500–700 | Заголовки, числа, метки кнопок |
| `--font-ui`      | **Onest**     | 400–600 | Абзацы, поля, служебные метки  |

Оба с родной кириллицей — для полностью русского интерфейса это
условие, а не пожелание. Веса ограничены тем, что используется:
полный набор начертаний стоил бы сотни лишних килобайт на
мобильном интернете посреди города.

Подключение — `app/layout.tsx` через `next/font/google`.

### Как применяется

```
h1, h2, h3        →  Unbounded 700, капитель
h4, h5, h6        →  Onest 600 (Unbounded на 15px в списке нечитаем)
body              →  Onest 400
.signal-label     →  «ДАТА», «СТАРТ» — капитель в разрядку 0.16em
.display-figure   →  числа: 05.09, 14:00, счёт, отсчёт
```

### Отступление от Figma

В макете служебные метки набраны 8–9px. На реальном телефоне в
солнечный день это нечитаемо, а мастер-промпт требует контраст
4.5:1 для основного текста и поля не меньше 16px. Пропорции
шкалы сохранены, абсолютные размеры подняты до пола **11px**.

Поля ввода — ровно 16px: меньше, и Safari на iPhone зумит
страницу при фокусе.

## Форма

Углы прямые. Радиус в системе один — **8px у игровой карточки**,
значение переменной `--card-radius` из Figma. Всё остальное:
кнопки, панели, поля, таблицы — `0`.

`--radius-pill` (9999px) остаётся для круглых элементов: точек
знака, маркеров, аватаров.

**Теней нет нигде.** Глубина передаётся контрастом поверхностей,
волосяной линией `#404045` и воздухом.

## Компоненты

### Кнопки

| Вариант     | Вид                                                  |
| ----------- | ---------------------------------------------------- |
| `primary`   | Сигнальная заливка, надпись цвета холста             |
| `secondary` | Холст, светлая рамка; при наведении рамка сигнальная |
| `ghost`     | Прозрачная, светлая подложка при наведении           |
| `danger`    | Контур сигналом, заливка при наведении               |

Разрушающее действие обозначается контуром, а не заливкой: иначе
оно спорило бы с основной кнопкой за внимание.

### Билетный CTA

Утилита `.ticket-notch` вырезает по бокам две половинки круга
цвета холста и превращает прямоугольник в билет, не добавляя ни
одной картинки. Хост обязан иметь `position: relative` и
`overflow: hidden`.

### Статусы

Статус различается **тремя независимыми признаками**: символ,
текст и стиль границы. Это требование доступности — по цвету
статус читаться не должен.

| Статус          | Значок          | Граница            |
| --------------- | --------------- | ------------------ |
| Принято         | `accepted`      | сигнальная заливка |
| Ожидает         | `pending`       | сплошная           |
| Проверяется     | `checking`      | пунктир            |
| Ручная проверка | `manual-review` | сплошная           |
| Отклонено       | `rejected`      | приглушённая       |

Отдельного красного для ошибок в системе нет вовсе — ошибки
помечаются значком `upload-failed` и усиленной границей.

### Значки

Один набор — [Lucide](https://lucide.dev), сетка 24×24, толщина
штриха 2. Единственная точка входа — `components/ui/icon.tsx`:
компоненты просят значок **по имени состояния**, а не по внешнему
виду (`<Icon name="accepted" />`, а не «галочка»). Полный список
имён виден на `/design-system`.

Так сделано не ради красоты вызова. Имя состояния переживает
смену рисунка: поменяется галочка на печать — правится одна
строка в карте `ICONS`, а не двадцать мест в разметке. И наоборот,
одинаковый рисунок в двух разных смыслах сразу видно в карте.

**Чего здесь больше нет.** Раньше значки набирались юникодом:
`◇`, `⁂`, `▦`, `⁋`, `◍`, `‖`. Затея была в том, чтобы обойтись без
иконочного шрифта, но получилось хуже по всем статьям. Символы
подбирались по тому, что нашлось в таблице, а не по смыслу: ромб
ничего не сообщал про задание, `⁂` — про ручную проверку. Части
не было в Unbounded, и браузер молча подставлял начертание из
другого шрифта, ломая строку. Восстанавливать их нельзя.

**Знаки типов заданий — исключение и живут отдельно**, в
`components/game/task-type-icon.tsx`. Фотоаппарат и бегущие
человечки нарисованы владельцем и обведены в контуры; заменять их
набором нельзя, они часть фирменного стиля, а не интерфейса.

### Полароид

Чёрно-белая улика лендинга, которая оживает при наведении. Цвет
возвращается CSS-фильтром `grayscale(1) → none`, а не подменой
файла: одна картинка, один запрос, переход без подгрузки.

### Два исключения из правила «только transform и opacity»

`filter` у полароида и переходы цвета (`color`, `background-color`,
`border-color`) у кнопок и ссылок. Ни то, ни другое не вызывает
пересчёта раскладки — браузер ограничивается перерисовкой, и на
бюджетном телефоне это не та стоимость, из-за которой правило
вводилось. Всё остальное — только `transform` и `opacity`, и это
проверяется: ни в одном `@keyframes` системы других свойств нет.

Ни одной анимации `width`, `height`, `top`, `margin` или
`box-shadow` в системе не существует.

Цвет возвращается только там, где есть настоящее наведение
(`@media (hover: hover) and (pointer: fine)`): на телефоне hover
залипает после тапа и снимок остался бы цветным навсегда.
Клавиатурный `:focus-visible` даёт тот же результат, что и мышь.

### Знак

Восемь точек сеткой 3×3 с пустым центром; нижняя правая набрана
сигнальным цветом. Из него же сделаны иконки PWA.

## Движение

Анимируются **только** `transform` и `opacity`. Эти два свойства
браузер считает на композиторе, не трогая раскладку: на дешёвом
телефоне посреди города это разница между «плавно» и «дёргается».
Ни одной анимации `width`, `height`, `top` или `box-shadow`.

```
.anim-rise       выезд снизу, 0.7s   — карточки, кнопки
.anim-fade       проявление, 0.9s    — служебные строки
.anim-headline   выход заголовка,    — ДВИЖ ПАТРУЛЬ
                 0.9s, из-под обрезки
.anim-draw       линейка прочерчива- — сигнальные линейки
                 ется слева направо
.anim-float      покачивание 7s      — полароиды
.anim-tick       пульс 1s            — отсчёт, статусы «в работе»
.anim-marquee    лента 38s linear    — бегущая строка
.delay-1 … 5     0.08 → 0.52s        — ступенчатый выход группы
```

Реакции на курсор:

```
.lift            подъём на 3px       — карточки, кнопки, строки
.underline-slide подчёркивание       — текстовые ссылки
.polaroid-host   возврат цвета       — снимки лендинга
```

### Переворот карточки

Figma «Motion / Card flip» (`100:68`): **420ms**, **perspective
900px**, только `rotateY`, никакой анимации раскладки.

```
.flip-scene   perspective: 900px
.flip-body    transform-style: preserve-3d, transition 420ms
              [data-flipped="true"] → rotateY(180deg)
.flip-face    backface-visibility: hidden
```

Обе стороны лежат друг на друге через `grid-area: 1 / 1`,
поэтому высота карточки не прыгает во время переворота.

### Карта вылетает из гнезда

Расклад руки и витрина лендинга открывают карту одинаково
(`components/game/card-table.tsx`): она лежит рубашкой вверх, по
нажатию рисуется поверх страницы сразу в конечном размере, но
первым кадром получает трансформацию, совмещающую её с гнездом.
Со следующего кадра трансформация снимается — 420ms, `ease-out`,
только `transform`.

Перелёт и переворот разложены по двум элементам: внешний везёт,
внутренний крутит `rotateY`. `scale` и `rotateY` в одной
трансформации дают перспективу, гуляющую по ходу полёта.

Окно живёт в портале у `body`. Любой `will-change` или `transform`
на секции выше делает элемент содержащим блоком для
`position: fixed`, и «на весь экран» превращается в «на весь блок
секции» — один раз на этом уже обожглись.

При `prefers-reduced-motion` карта просто появляется на месте.

### prefers-reduced-motion

Настройка не просто убирает анимации, а возвращает элементы в
конечное состояние через `!important`. Убрать анимацию было бы
недостаточно: появляющийся контент остался бы невидимым.

Переворот при этом остаётся мгновенным, а не отменяется: Figma
`100:83` требует именно этого. Иначе кнопка «перевернуть»
перестала бы что-либо делать.

## Доступность

- Основной текст `#f5f5f1` на холсте — 18.7:1.
- Абзацы `#a3a3a8` — 9.1:1.
- Служебное `#83838b` — 5.4:1 на холсте, 4.85:1 на панели.
- Сигнал `#ff00b3` на холсте — 5.3:1; тёмный текст на сигнале — 8.9:1.
- Зона нажатия на мобильном — минимум 44×44px (`.tap-target`).
- Фокус — сигнальная обводка 2px с отступом 2px.
- Масштабирование не запрещено (`maximumScale: 5`).
- Статус различим без цвета.
- Лицевая и оборотная стороны карточки корректно скрываются от
  скринридера: невидимая сторона получает `aria-hidden`.

## Проверка

Открыть `/design-system` и сверить:

- [ ] фон страницы `#060609`, не чёрный и не серый;
- [ ] текст `#f5f5f1`, не белый;
- [ ] углы прямые, единственный радиус — 8px у карточки;
- [ ] ни одной тени;
- [ ] сигнальных элементов на экране один-два, не больше;
- [ ] крупные заголовки — Unbounded в капители;
- [ ] абзацы — Onest, 13–17px;
- [ ] статус различим без цвета;
- [ ] кнопки на мобильном не меньше 44px;
- [ ] одна навигационная панель на странице;
- [ ] при включённом «меньше движения» всё видно сразу и неподвижно.
