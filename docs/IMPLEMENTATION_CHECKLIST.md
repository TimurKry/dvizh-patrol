## 2. Игровые карточки и гонка команд

- [ ] Команда имеет один из шести цветов: red, green, blue, yellow, orange, pink.
- [ ] Цвет команды хранится в БД и управляет рубашкой и орнаментом карточек.
- [ ] Рука содержит 6 карточек: 2 загадки, 2 фото, 2 актива.
- [ ] Карточки выдаются сервером случайно и не раскрывают весь пул заданий.
- [ ] Flip работает по tap/click и доступен с клавиатуры.
- [ ] Переворот: 420ms, perspective 900px, только transform/opacity.
- [ ] Первая валидная принятая отправка атомарно забирает задание глобально.
- [ ] После глобального захвата карточка исчезает у всех команд и рука пополняется.
- [ ] Конкурирующие отправки получают понятный статус без ошибочного начисления.
- [ ] Баллы берутся из задания; диапазон не захардкожен до утверждения контента.
