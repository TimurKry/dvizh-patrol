# Формат импорта заданий

Задания загружаются файлом JSON или CSV на странице
`/admin/import`.

**Импорт выполняется целиком.** Если хотя бы одна запись
некорректна, не сохраняется ничего. Половина заданий в базе —
худший исход для организатора: непонятно, какие доехали.

Готовые образцы: [`data/tasks.example.json`](../data/tasks.example.json)
и [`data/tasks.example.csv`](../data/tasks.example.csv) — 30 заданий.

## Поля

| Поле               | Тип                    | Обяз. | По умолчанию | Описание                          |
| ------------------ | ---------------------- | :---: | ------------ | --------------------------------- |
| `number`           | целое > 0              |  да   | —            | Номер. Уникален в мероприятии     |
| `title`            | строка 2–140           |  да   | —            | Название                          |
| `shortDescription` | строка ≤ 200           |  нет  | —            | Одна строка для карточки          |
| `description`      | строка 10–4000         |  да   | —            | Полное условие                    |
| `points`           | целое 0–1000           |  да   | —            | Стоимость                         |
| `category`         | перечисление           |  да   | —            | См. ниже                          |
| `difficulty`       | `easy`/`medium`/`hard` |  нет  | `medium`     | Сложность                         |
| `validationMode`   | `auto`/`ai`/`manual`   |  нет  | `manual`     | Как проверяется                   |
| `criteria`         | массив строк ≤ 12      |  нет  | `[]`         | Что проверять                     |
| `minimumPeople`    | целое 0–10             |  нет  | `0`          | Людей в кадре                     |
| `maxAttempts`      | целое 1–10             |  нет  | `2`          | Попыток                           |
| `requireLocation`  | логическое             |  нет  | `false`      | Нужна ли геопозиция               |
| `latitude`         | число −90…90           | усл.  | —            | Обязательно при `requireLocation` |
| `longitude`        | число −180…180         | усл.  | —            | Обязательно при `requireLocation` |
| `radiusMeters`     | целое 10–20000         | усл.  | —            | Обязательно при `requireLocation` |
| `active`           | логическое             |  нет  | `true`       | Показывать ли                     |

### Категории

`monuments` · `road_signs` · `advertising` · `interaction` ·
`object_search` · `team` · `creative` · `special`

### Режимы проверки

| Режим    | Поведение                                              |
| -------- | ------------------------------------------------------ |
| `auto`   | Принимается сразу после загрузки, баллы начисляются    |
| `ai`     | Проверяется автоматически, спорное уходит организатору |
| `manual` | Каждая фотография попадает к организатору              |

Режим `ai` **требует хотя бы одного критерия** — иначе проверять
нечего, и файл не пройдёт.

## JSON

```json
[
  {
    "number": 1,
    "title": "Повторите дорожного рабочего",
    "shortDescription": "Найдите знак и повторите позу",
    "description": "Найдите треугольный знак дорожных работ...",
    "points": 50,
    "category": "road_signs",
    "difficulty": "easy",
    "validationMode": "ai",
    "criteria": [
      "Виден треугольный знак дорожных работ",
      "Видно минимум два участника",
      "Участники повторяют действие со знака"
    ],
    "minimumPeople": 2,
    "maxAttempts": 2,
    "requireLocation": false
  }
]
```

Корень — массив. Объект вместо массива не принимается.

## CSV

Первая строка — заголовки. Разделитель — запятая или точка с
запятой. Кодировка UTF-8, BOM допускается (его добавляет Excel).

```csv
number,title,description,points,category,criteria,validationMode
1,Знак,"Найдите знак и повторите действие.",50,road_signs,"Виден знак | Видно двоих",ai
```

**Критерии разделяются символом `|`** или переводом строки внутри
поля.

Переводы строк и запятые внутри значения допустимы, если поле
взято в кавычки. Кавычка внутри поля удваивается — стандарт
RFC 4180.

### Русские заголовки

Понимаются оба варианта:

```
номер, название, краткое, описание, баллы, категория,
сложность, проверка, критерии, минимумлюдей, попытки, активно
```

Неизвестные колонки не ломают импорт, но о них сообщается.

## Проверка перед импортом

1. Разбор файла (JSON или CSV).
2. Проверка каждой записи схемой Zod.
3. Поиск повторяющихся номеров.
4. Предпросмотр: что будет загружено.
5. Список ошибок с номерами строк.
6. Подтверждение.

Ошибки можно скачать отдельным CSV и отправить автору файла:

```csv
строка,номер_задания,поле,ошибка
3,2,points,"Ожидалось число"
7,5,criteria,"Режим «ai» требует хотя бы одного критерия"
```

Для CSV номер строки учитывает заголовок: первая запись — строка 2.

## Замена существующих

Флажок «Заменить существующие задания» удаляет те задания, по
которым **ещё нет ни одной отправки**. Задания с отправками
остаются: их удаление разорвало бы историю начислений.

Без флажка задания с совпадающими номерами перезаписываются,
остальные добавляются.

## Обратный экспорт

`/api/admin/export/tasks` выгружает задания в **том же формате**.
Файл можно загрузить в следующее мероприятие — набор заданий
переносится целиком.

## Частые ошибки

| Сообщение                                                          | Причина                                      |
| ------------------------------------------------------------------ | -------------------------------------------- |
| «Ожидался массив заданий»                                          | JSON начинается с `{`, а не с `[`            |
| «Номер N уже использован в строке M»                               | Повтор `number`                              |
| «Режим «ai» требует хотя бы одного критерия»                       | Пустой `criteria` при `validationMode: "ai"` |
| «Для проверки геопозиции нужны latitude, longitude и radiusMeters» | Включён `requireLocation` без координат      |
| «Неизвестные колонки»                                              | Опечатка в заголовке CSV                     |
| «Файл не является корректным JSON»                                 | Лишняя запятая, одинарные кавычки            |
