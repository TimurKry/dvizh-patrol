# App Preview · Движ-Патруль

Вертикальный ролик 36 с / 1080×1920 / 30 fps, объясняющий игровой
цикл: код → команда → карточки → карта → выполнение → фотография →
проверка → баллы → история → рейтинг → финал.

Проект изолирован: свой `package.json`, свои зависимости, своя
папка `node_modules`. Приложение он не трогает и в его сборку не
попадает.

## Команды

```bash
cd video/app-preview
npm install                 # зависимости композиции

npm run preview             # студия Remotion в браузере
npm run render              # финальный MP4 в renders/
npm run cover               # обложка PNG
```

Рендер требует Chromium в режиме headless shell. В этом окружении
он лежит по пути из `--browser-executable` в скриптах; на другой
машине путь можно убрать — Remotion скачает свой.

## Что откуда берётся

| Что | Где |
| --- | --- |
| Снимки экранов | `assets/screens/*.png` |
| Шрифты Unbounded и Onest | `assets/fonts/*.woff2` |
| Логотип | `assets/logo.png` |
| Сцены и тайминг | `src/Preview.jsx` |
| Телефон, крупный план, подписи, маршрут | `src/parts.jsx` |
| Цвета и длительность | `src/theme.js` |

`public` — симлинк на `assets`: `staticFile()` Remotion ищет файлы
именно в `public`, а структура проекта задана через `assets`.

## Замена кадров

Экраны сняты настоящим браузером на мобильном вьюпорте 390×844 при
плотности 3 — то есть 1170×2532 пикселя. Пересъёмка:

1. поднять стенд: `npm run db:qa`, затем `node scripts/qa-rest.mjs`
   и `npm run start` в корне проекта;
2. войти тестовой командой и снять нужные экраны Playwright'ом в
   `video/app-preview/assets/screens/` с тем же вьюпортом;
3. имя файла — это ключ, по которому сцена его находит.

Крупные планы задаются полем `crop: [x, y, ширина, высота]` в
пикселях исходника. Линейка — прямо по снимку: цифры совпадают с
тем, что видно в редакторе изображений. Так кадр укрупняется, но
остаётся настоящими пикселями приложения, а не пересобранной
вёрсткой.

## Изменение текста

Все подписи лежат в `src/Preview.jsx` рядом со своей сценой.
Правило то же, что в ролике: 2–5 слов, не меньше 1,2 с на чтение.
Безопасная зона Reels задана в `parts.jsx` — `SAFE`.

## Данные мероприятия

Дата, время, цена и состав команды в финале взяты из базы:

```sql
select starts_at, price_cents / 100, team_size, city from public.events;
```

Перед перерендером стоит сверить их ещё раз — на 27.08.2026 это
05.09.2026, 14:00, 15 €, до 5 человек, Leipzig.

## Звук

Ролик отрендерен **без музыки и без звуковых эффектов**: взять или
синтезировать аудио в этом окружении нечем. Дорожка в файле есть,
но она пустая.

Когда трек появится, подкладывается одной командой:

```bash
ffmpeg -i renders/dvizh-patrol-app-preview-1080x1920.mp4 \
       -i audio/track.mp3 \
       -map 0:v -map 1:a -c:v copy -shortest \
       renders/dvizh-patrol-app-preview-music.mp4
```

Либо через саму композицию — тогда звук встанет по кадрам:
положить файл в `assets/audio/`, добавить `<Audio src={staticFile(
'audio/track.mp3')} />` в `Preview.jsx` и перерендерить. Второй
способ лучше: акценты можно свести с монтажом кадр в кадр.

Опорные точки для сведения (кадры при 30 fps):

| Кадр | Секунда | Событие |
| ---: | ---: | --- |
| 0 | 0:00 | точка появляется |
| 62 | 2:02 | маршрут дочерчен, логотип |
| 90 | 3:00 | вход по коду |
| 180 | 6:00 | рука команды |
| 270, 320, 370 | 9:00, 10:2, 12:1 | три типа карточек |
| 486 | 16:06 | переход на карту |
| 660 | 22:00 | отправка |
| 764 | 25:14 | «засчитано», всплеск |
| 810 | 27:00 | открывается история |
| 940 | 31:10 | подъём в рейтинге |
| 1068 | 35:18 | финальная вспышка |
