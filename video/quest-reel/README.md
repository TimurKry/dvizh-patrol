# Ролик «как это было»

Лента пар «задание → результат»: сверху эталон, который команда
повторяла, крупно — то, что у неё вышло. Кадры листаются как в
телефоне, на прилёте щёлкает затвор.

## Материал

Фотографий в репозитории нет и не будет: это лица людей, и весят
они девяносто семь мегабайт. Проект работает на заглушках, пока
настоящий материал не положат рядом.

```
# заглушки — чтобы просто посмотреть, как выглядит
node make-placeholders.mjs 8

# настоящее — из корня репозитория, ключ из панели Supabase
SUPABASE_URL=https://…supabase.co \
SUPABASE_SERVICE_ROLE_KEY=… \
node scripts/export-video-pairs.mjs --out video/quest-reel/public/pairs --no-zip
```

Оба сценария кладут в `public/pairs/` картинки, `pairs.json` с
подписями и `totals.json` с цифрами финала.

## Сборка

```
npm run sounds     # синтезировать щелчок затвора и шорох (уже в public/)
npm run preview    # студия Remotion
npm run render     # renders/dvizh-patrol-quest-reel.mp4
npm run light      # то же, но лёгкое — переслать в мессенджер
```

`node_modules` — симлинк на соседний видеопроект: Remotion весит
сотни мегабайт, и держать две копии ради одного и того же набора
незачем.

## Что где настраивается

| хочу | где |
|---|---|
| быстрее/медленнее листать | `src/theme.js`, `STEP` и `HOLD` |
| длиннее заставку | `src/theme.js`, `INTRO` и `OUTRO` |
| другой текст заставки | `src/Reel.jsx`, блок «Заставка» |
| убрать вспышку | `src/Reel.jsx`, снять `<Flash>` |
| тише затвор | `src/Reel.jsx`, `volume` у `<Audio>` |
| сколько кадров в ленте | `--limit` у выгрузки |

Музыки нет намеренно: у этой машины нет выхода в сеть, а у любой
дорожки своя лицензия. Щелчки синтезированы (`make-sounds.mjs`),
музыку проще положить сверху в монтажке.
